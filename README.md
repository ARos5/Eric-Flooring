# The LVP Warehouse — Jacksonville · Newsletter

An automated email newsletter for **The LVP Warehouse — Jacksonville** (Eric Borrelli's
luxury-vinyl-plank flooring business). It pairs **Northeast Florida real estate market data** — the
hook this audience (investors, flippers, contractors, repeat buyers) cares about — with **flooring
showcases and promotions**, so The LVP Warehouse stays top-of-mind for the next flip.

Built from a call between Alex and Eric (2026-06-25) using a spec → build → review pipeline.
